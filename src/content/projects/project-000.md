title: Products Launcher — Microservices Architecture
description: Distributed e-commerce backend built as five independent NestJS microservices communicating over a NATS broker, with an API Gateway as the single public entry point. Features polyglot persistence with Prisma across PostgreSQL, MongoDB and SQLite, JWT authentication with guards and token renewal, and a full payment flow with signature-verified webhooks. Each service lives in its own repository as a git submodule, ships multi-stage production Docker images, and the API is documented with Swagger.
